# M8 Allocation — WSH-REQ-0072

The public ABI documents and verifies explicit allocator ownership, bounded
objects, strict UTF-8 views, structure initialization, runtime version
negotiation, synchronous callback lifetime, same-evaluator reentry refusal,
cooperative runtime cancellation, and defined misuse results.

**Verification:** `TC-0100`, `TC-0101`, `TC-0103`, `TC-0104`, `TC-0105`
