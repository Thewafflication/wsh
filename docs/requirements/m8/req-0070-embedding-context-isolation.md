# M8 Allocation — WSH-REQ-0070

M8 verifies that an embedding host observes the isolated context ownership
established by the M2, M5, and M6 allocations, including variables,
diagnostics, runtime state, paths, descriptors, and children.

**Verification:** `TC-0100`, `TC-0102`; inherited isolation cases from M2,
M5, and M6 provide the complete cross-milestone ownership evidence.
